# Manual rápido por rol

La capacitación interactiva dentro de Web/Móvil es la réplica principal. Esta guía indica qué resultado debe practicar cada rol; no reemplaza permisos ni autoriza excepciones.

| Rol            | Configura/ejecuta                                                                                                        | Nunca debe hacer                                                        |
| -------------- | ------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------- |
| Administración | usuarios, localidades, rutas/cobradores, clientes, ventas, ajustes autorizados, cortes, devoluciones, revisiones offline | borrar movimientos o compartir credenciales.                            |
| Contabilidad   | cartera, abonos, cortes, devoluciones, reportes, conciliación y selector de proveedor                                    | cambiar seguridad global ni operar caja ajena sin quedar como operador. |
| Almacén        | productos/fotos, compras, entradas, pedidos, proveedor y revisión física                                                 | autorizar devolución/reembolso o consultar cartera completa.            |
| Venta          | cliente, venta contado/crédito y pedido                                                                                  | elegir proveedor, costo de compra o ajustar saldo.                      |
| Cobranza       | ruta asignada, cliente extraordinario permitido, visita, abono, venta/entrega y sincronización                           | ver otra cartera, cambiar proveedor o editar un recibo rechazado.       |

Orden inicial: Administración crea usuarios/localidades/productos; asigna cobradores a rutas y clientes; Almacén carga existencia/proveedores; después Venta/Cobranza operan. Antes de dinero real, cada persona completa su simulador correcto y un caso de error.
