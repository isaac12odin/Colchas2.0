# Capacitación y soporte

La versión de capacitación coincide con la versión SemVer de web/móvil. Las lecciones simples son recorridos guiados; venta crédito, abono, entrega, devolución y conflicto offline son simuladores en memoria que nunca llaman `/api/`.

Certificación opcional por rol: completar preparación, camino correcto y un error de cada flujo sensible; el responsable registra persona, rol, versión, fecha y resultado fuera de la base operativa. No se guardan respuestas de práctica como movimientos reales.

Canal de soporte, horario y SLA deben completarse antes del piloto. Un ticket contiene versión, rol, pantalla, hora, código/folio e ID de correlación; nunca teléfono/dirección completos, contraseña, token o foto. P0/P1 siguen runbook y guardia; dudas de uso siguen la base de conocimientos.

Errores frecuentes: `STOCK_INSUFICIENTE` (Almacén concilia), `ABONO_EXCEDENTE` (capturar importe correcto), `JORNADA_CERRADA` (Contabilidad), `CLIENTE_NO_ASIGNADO` (Administración revisa ruta), `RELOJ_ADELANTADO` (hora automática), `SESION_REVOCADA` (login), `HUELLA_LOTE_INVALIDA` (detener equipo y escalar).

La interfaz está íntegramente en español. `docs/README.en.md` es un resumen técnico para incorporación; no se declara paridad de manuales en inglés hasta que exista revisión humana completa.
